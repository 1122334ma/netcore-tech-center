# 常见故障排查

## 一、路由器突然无法上网

可能原因与处理：
1. **长时间运作/过热死机**：重启路由器。
2. **网线或网口接触不良/损坏**：重插 WAN 口网线，或更换网线测试。
3. **宽带欠费/运营商问题**：把宽带线直连电脑，确认能否上网；不行则联系运营商。
4. 以上排查后仍异常 → 联系磊科客服 400-810-1616。

## 二、保存设置后仍无法上网

- 确认宽带线没有插到 LAN 口。
- 回到「上网设置」核对：拨号 / 自动获取 / 静态 IP 是否选对。
- 拨号方式下，账号密码以运营商提供为准。

## 三、网络不稳定 / 掉线

1. **摆放位置**：避免狭小空间（抽屉、衣柜），天线立起，高度适中。
2. **选对信号**：近距离连 5G，远距离/有遮挡连 2.4G。
3. **调整信道**：管理页无线设置中改信道，或勾选「智能优选」。
4. 桥接场景：把副路由移到主路由信号更稳处。

## 四、忘记 WiFi / 管理密码

- 忘记 WiFi 密码：进管理页修改即可。
- 忘记管理登录密码：
  - 方式一：恢复出厂设置，用默认管理密码进入并重置。
  - 方式二（部分机型）：使用机身「一键通」按钮，立即恢复上一次正确设置（适用于 NB1200C、NB1200GC、NB2100G、NB800C）。

## 五、如何恢复出厂设置

1. 路由器通电。
2. 用牙签/笔尖长按 **Reset / Default** 小孔 5–10 秒。
3. 所有指示灯同时亮起时松开。
4. 等待约 1 分钟系统重启稳定后再连 WiFi。

## 六、无线桥接后不能上网

| 现象 | 处理 |
| --- | --- |
| 扫描不到主路由 WiFi | 缩短距离；检查主路由是否隐藏网络或不支持的频段 |
| 输密码连不上 | 核对名称、密码、加密方式 |
| 已连接不能上网 | 检查是否拿到地址；排查管理地址/DHCP 冲突 |
| 网速慢/掉线 | 移动副路由到信号更稳处，避遮挡 |
