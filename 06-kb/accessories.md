1.1.2、监控摄像头添加不上

**现象**：部分摄像头不兼容的问题，摄像头获取不到 IP 地址。
网桥配置正确，网桥放到网络环境后摄像头无法获取到 IP 地址，识别到的 IP 都是摄像头默认 IP 地址，由于地址冲突无法添加。
解决方法：拿下来摄像头到硬盘录像机处，连接上手动激活（获取到 IP）后再重新装回去。即需要先把摄像头跟 NVR 直连激活后再使用。

1.1.3、150 个以上的摄像头环境，偶尔有些摄像头没有监控画面？

**现象**：装好了有画面，断电或过一段时间部分监控没有画面了。
如果一小区全用这个型号，在一个大的局域网下，由于网桥自动获取 IP 地址，在 IP 地址池有限且没有划分 VLAN 的情况下，会出现跟摄像头和网桥之间抢 IP 地址的情况，尤其是摄像头超过 150 个，IP 地址使用的是 2-254 的地址段，容易出现这样的问题。
解决方法：在路由器或三层交换上做绑定 IP/MAC，尤其是网桥的 IP/MAC。

1.1.4、网桥对焦角度问题

磊科 NC 系列网桥采用的是定向天线，所以网桥有一个辐射传输角度问题，网桥不管什么品牌的都是以定向天线为主。
磊科网桥传输角度：水平 60°，上下 30°
也就是主从网桥，不管是一对一、还是一对多，都建议在水平 60°上下 30°的夹角范围内效果最佳。

1.1.5、网桥 2 个指示灯 LAN 不亮，但是其他灯正常（如下图）

说明网桥供电正常，问题大概率出现在了网线、水晶头上，重新做水晶头后用测线仪测试保证 8 芯全通。

**原因**：24V 非标 POE 网桥是使用的网线需要是 8 芯，也就是说 1236 供网、4578 供电，当出现 1236 某 1-2 个线序出现接触不好或不通的时候就会出现设备除了 LAN 口灯不亮其他灯正常的情况。
