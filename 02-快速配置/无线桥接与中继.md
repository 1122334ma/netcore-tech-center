# 无线桥接与中继

当单台路由器覆盖不足时，用副路由器接收主路由信号，扩展 WiFi 范围。

## 准备工作

- 记下主路由器的 WiFi 名称与密码。
- 把副路由器放在主路由仍有稳定信号的位置。
- 副路由若用过且状态不明，先复位到可登录状态，减少旧配置干扰。

## 设置步骤（通用）

1. 手机/电脑连接副路由器的管理 WiFi，或网线接 LAN 口，进入管理界面。
2. 在「无线设置 / 上网设置 / 工作模式」附近找到 **无线桥接 / WISP / 中继 / WDS** 选项。
3. 扫描并选择主路由器的 WiFi，按主路由的加密方式填写密码，保存。
4. 重连后，在「运行状态 / 网络状态」查看是否已获取地址、显示已连接，或直接打开网页测试。

## 主副路由分工

- **主路由**：负责宽带接入、地址分配。
- **副路由**：接收无线信号并扩展覆盖，不再重复拨号。
- 两台管理地址不要相同，否则可能进错设备或打不开页面。

## 桥接后不能上网的排查

| 现象 | 处理 |
| --- | --- |
| 扫描不到主路由 WiFi | 缩短两台距离；检查主路由是否隐藏网络或用了副路由不支持的频段 |
| 输密码后连不上 | 核对 WiFi 名称、密码、加密方式 |
| 已连接但不能上网 | 检查副路由是否拿到地址；排查两台管理地址 / DHCP 是否冲突 |
| 网速慢 / 掉线 | 把副路由移到主路由信号更稳处，避开厚墙与金属遮挡 |

> 也可使用 Mesh 组网实现更无缝的覆盖（见「高级功能 / Mesh 组网」）。
