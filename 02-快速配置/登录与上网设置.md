# 登录与上网设置

## 一、进入管理界面

1. 路由器通电，WAN 口接好宽带，手机/电脑连接路由器的 WiFi 或有线网络。
2. 浏览器地址栏输入 `leike.cc`，或机身铭牌标注的管理地址（常见 `192.168.1.1`、`192.168.2.1`）。
3. 输入管理账号密码（默认管理密码在设备底部标签）。
4. 点击「快速配置 / 上网设置」开始。

> 找不到入口时，可在手机/电脑的「网络详情」中查看默认网关地址。

## 二、选择上网方式

| 上网方式 | 适用场景 | 填写内容 |
| --- | --- | --- |
| 宽带拨号（PPPoE） | 运营商提供账号密码 | 宽带账号 + 密码 |
| 自动获取（DHCP） | 光猫已拨号，路由自动拿地址 | 无需填写 |
| 静态 IP | 运营商明确给出 IP/网关/DNS | IP、子网掩码、网关、DNS |

- **路由模式**：路由器分配 IP 并做 NAT 转发（最常见的家庭/企业用法）。
- **桥接模式**：路由器当 AP 用，由光猫/上层分配 IP。

## 三、设置无线名称与密码

1. 修改 2.4G 与 5G 的无线名称（SSID）。
2. 设置 8 位以上 WiFi 密码。
3. 建议勾选「将无线密码设为路由器管理密码」，减少记忆负担。
4. 保存后，原连接设备会断开一次，用新名称/密码重连即可。

## 四、判断是否联网成功

- 管理页 WAN 状态显示「已连接 / 已获取地址」。
- 用一台设备打开网页或 App 测试，能访问即配置完成。

> 双频路由器：近距离优先连 5G（更快），远距离/有遮挡优先连 2.4G（更远）。
