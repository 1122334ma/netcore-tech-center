# IPTV 与 IPv6 配置

## 一、IPTV 配置

### 方式 A：桥模式透传 IPTV 业务
1. 登录管理界面，进入「网络 - 模式配置」。
2. 管理 IP 模式选「桥模式」，保存生效。
3. 由光猫/上层统一承载 IPTV。

### 方式 B：VLAN 绑定 IPTV 端口
1. 进入「应用 - IPTV 设置」。
2. 勾选「使能」，配置 LAN 口绑定的 VID（如 45）。
3. 保存后，下挂 IPTV 设备即可正常获取业务。

## 二、IPv6 配置（以 NX1-T 为例）

1. 「网络 - Internet 连接」中将 IP 协议改为 **IPv4/IPv6 双栈**，开启 IPv6。
2. WAN 获取方式（全局地址、网关、DNS）建议选「自适应」，兼容 SLAAC 与 DHCPv6。
3. 「状态 - 网络侧信息 - IPv6 连接信息」查看是否拿到合法 IPv6 地址、前缀、DNS。
4. 给下挂设备分配 IPv6：进入「网络 - LAN 侧地址配置 - RA 配置」，开启 RA（SLAAC 无状态分配）。
5. 插拔客户端网线后，客户端网卡应获取到 IPv6 地址并正常通信。

> 不同型号菜单名称可能不同，但双栈 + 自适应获取是通用思路。
