# 固件升级

升级固件可修复问题、提升稳定性与功能。请务必谨慎操作。

> 将固件文件放入 `public/firmware/` 目录后，下载链接自动生效。链接格式为 `/firmware/文件名`。

## 升级步骤（通用）

1. 点击上表对应型号的下载链接，保存固件文件到电脑。
2. 进入路由器管理界面（浏览器输入 `192.168.1.1` 或设备标注地址）。
3. 找到「系统工具 / 软件升级 / 固件升级」。
4. 选择下载好的固件文件，开始升级。
5. 升级过程中**切勿断电**，等待设备自动重启完成。

## 注意事项

- 升级前建议记录重要配置，必要时先备份。
- 断电可能导致设备变砖，务必保证供电稳定。
- **仔细核对型号与适用系统版本**，避免刷入错误固件。
- 若升级后异常，可恢复出厂设置（见「故障排查 / 忘记密码与恢复出厂」。

> 部分机型支持「手机升级系统」，可在微信绑定后或管理页内操作。
