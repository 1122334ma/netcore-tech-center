# Mesh 组网与微信绑定

## 一、Mesh 组网

多台支持 Mesh 的磊科路由器/AP 可无线回程组网，实现大面积无缝覆盖，终端在节点间自动漫游。

### 通用要点
- 主节点接宽带并正常上网后，再添加子节点。
- 子节点放在主节点信号仍良好的位置，逐步向外扩展。
- 建议使用相同品牌/系列的 Mesh 设备，兼容性更佳。

### 与桥接的区别
- **桥接/中继**：手动扩展，可能需分别连接不同 SSID。
- **Mesh**：统一 SSID，自动漫游，体验更无缝。

## 二、微信绑定路由器

1. 路由器通电通网，手机连接路由器的 WiFi。
2. 浏览器输入 `leike.cc` 登录管理界面。
3. 点击「电脑版」，选择「用手机管理路由器」，将显示的二维码截屏保存。
4. 用微信「扫一扫」该二维码，点击「立即绑定新路由」即可。

> 绑定后可在微信中查看状态、接收通知，便于远程维护（部分机型支持微信云管理，如 NS210GPM）。
